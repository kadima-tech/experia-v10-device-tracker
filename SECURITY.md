# Security Policy

## Supported versions

Security fixes are provided for the latest release only. Older releases are not supported.

## Reporting a vulnerability

Report a vulnerability privately through GitHub private vulnerability reporting for this repository:

https://github.com/kadima-tech/experia-v10-device-tracker/security/advisories/new

That opens a private security advisory. Please do not open a public issue for a security report.

GitHub documents the process at https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability.
